# Simon and Picco's Games

One page that links to every current game Simon and Picco have made, so there is a single address to remember.

**Play:** https://augustineiacopelli.github.io/kids-games/

## Adding a game
Open `index.html`, find the `KIDS` list near the bottom, and copy one of the game lines into the right kid's list. Give it an emoji, a title, the game's GitHub Pages address, a short description, and a tag. Commit the change and the page updates in about a minute.

## Notes
- One self-contained `index.html`, no build step and no dependencies.
- This is separate from the AppADay portal.
